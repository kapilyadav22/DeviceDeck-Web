02 / FAQ

Before you start.

Which monitors work?

Device Deck can dim detected displays with software when hardware brightness is unavailable. Hardware brightness and input switching depend on the display, connection, and adapter.

How do profiles switch automatically?

Save your current setup under Profiles, then pick a connected monitor or USB hub under Apply on connection. Leave Device Deck running in the menu bar and reconnect the selected hardware.

How do I set a charge limit?

Open the Battery tab and select Set Charge Limit in System Settings. Apple offers limits from 80% to 100% on Apple silicon Mac notebooks with macOS Tahoe 26.4 or later.
